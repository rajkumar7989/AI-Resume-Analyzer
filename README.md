# 🤖 AI Resume Analyzer

AI Resume Analyzer is a Python Flask web application that analyzes resumes, compares them with job descriptions, identifies matched and missing skills, calculates resume-job matching scores, recommends suitable career roles, and stores analysis history using MySQL.

## 🚀 Features

- 📄 Resume PDF Upload
- 🔍 Resume Content Analysis
- 💼 Job Description Comparison
- ✅ Matched Skills Identification
- ❌ Missing Skills Identification
- 📊 Resume-Job Matching Score
- 🎯 Career Role Recommendations
- 💾 Analysis History Storage
- 🤖 AI-powered Resume Analysis
- 🌐 User-friendly Web Interface
